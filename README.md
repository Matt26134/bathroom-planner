# Bathroom Planner V1.8.1

Tile visual correction.

Fixed from V1.8.0:
- Granley pink feature wall now uses a correctly proportioned herringbone repeat
  instead of the squashed horizontal-stripe effect.
- Main 300 x 600 marble tile defaults to landscape orientation.
- Added Landscape / Portrait tile orientation per surface zone.
- Full tiled walls now respect the window and door openings instead of drawing
  a texture plane over the opening.
- Surface zone metadata shows orientation.

Existing V1.8 data is preserved.
