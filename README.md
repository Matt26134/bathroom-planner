# Bathroom Planner V1.8.4

Cleanup pass based on the latest screenshots.

## Fixed
- softened the 3D door so it no longer swings so aggressively into the room
- corrected the shower hardware to the vanity-side back wall

## Update
1. Extract the ZIP.
2. Upload all files to the repo root, replacing the old ones.
3. Commit changes.
4. Open the app and tap **Reload latest**.
