# Bathroom Planner V1.8.5

This build rolls the latest fixes and the queued 1.8.5 improvements into one package.

## Included
- cleaner 3D door model with hinge side and open-angle controls
- shower mount side control for shower items
- shower hardware rendered on the chosen side of the back wall
- refreshed pink herringbone feature-tile texture
- feature-zone helper buttons: **Fit zone to vanity** and **Set full height**
- built-in tile definitions refresh automatically so existing projects pick up the newer tile texture

## Update
1. Extract the ZIP.
2. Upload all files to the repo root, replacing the old ones.
3. Commit changes.
4. Open the app and tap **Reload latest**.

## Notes
- To edit the door, tap the door opening and use **Hinge side** and **Open angle**.
- To edit the shower hardware side, tap the shower tray and use **Shower mount side**.
- To place the feature wall more precisely, open the zone in **Surfaces** and use the helper buttons or the exact start/end/top/bottom fields.
