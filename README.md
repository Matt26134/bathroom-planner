# Bathroom Planner V1.4.0

Complete replacement package.

Major V1.4 changes:
- full-screen Focus planning mode
- bottom-sheet object editing
- Overview / Selected / All measurement modes
- manual Measure tool with edge snapping
- automatic nearest-neighbour/wall dimensions
- door/window dimensions and tappable opening editors
- door swing clearance zone + collision warnings
- design tolerance warnings
- visual snap guides while dragging
- dynamic grid as you zoom
- service-point markers (hot, cold, waste, soil, electrical)
- custom rectangle object
- mobile pinch zoom + pan retained
- local autosave + JSON backup retained

Easy update:
1. Extract this ZIP.
2. Upload ALL 8 files to the ROOT of the existing bathroom-planner repository.
3. Commit the changes.
4. Open the GitHub Pages app and tap Reload latest if needed.

No deleting or renaming is required.
