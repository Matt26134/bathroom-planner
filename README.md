# Bathroom Planner V2.4.2

Complete replacement build for the Bathroom Planner GitHub Pages PWA. Upload every file from this folder over the repository root. Existing `bathroomPlannerStable` data is migrated forward in place.

## V2.4.2 — live exact-detail editing

- Exact Details now stays open while you edit an item instead of collapsing after every field change.
- Number/text fields update the selected item live as you type, so the plan moves/resizes in the background without interrupting the edit.
- When editing from the 3D view, the Three.js scene also refreshes live behind the details panel.
- Select controls such as mounting host, finish and glass style update without closing the panel.
- Changes are autosaved with a short debounce, while undo checkpoints are taken when you start editing a field rather than on every keystroke.

## V2.4 — quality, geometry and 3D reliability

- Refactored the large inline application into real `app.js` and `styles.css` files while keeping the same no-build GitHub Pages deployment.
- Project schema upgraded to v5. Portable `.bathplan` export/import now uses the current schema instead of silently forcing old schema v3 data.
- Shower glass is now an independent **Glass panel** item rather than being generated by a stud wall.
- Glass panels can be mounted to a room wall, mounted above a stud, or left free-positioned. They support plain clear, fluted/reeded and frosted glass, privacy level, thickness and black/chrome/brass trim.
- Fluted shower glass now uses a thin physical glass surface with a procedural reeded bump treatment instead of chunky opaque ribs. The fluted face is kept on the outside of a stud-mounted shower screen, leaving the shower-facing side visually smoother.
- Mirrors, rain heads, hand showers and shower controls now share one wall-mount model: host surface, position along host and height.
- 3D Move respects wall mounting. Wall fixtures move along/up their wall or stud instead of sliding around the floor plan.
- Door geometry now shows the calculated frame/jamb allowance as well as using it for the actual hinge pivot. Example: 861mm framed width and 760mm leaf = 50.5mm allowance at each side.
- Door hinge labels are now `Toward window wall` / `Away from window wall` rather than ambiguous top/bottom terminology.
- Room-wall naming is standardised: Window wall, Door wall, Vanity wall / opposite door, and Far wall / opposite window.
- Walkthrough mode now has basic collision against major floor fixtures and stud walls.
- Three.js scene rebuilds now dispose dynamic materials as well as geometry to reduce long-session memory growth on mobile.
- Structure mode now supports surveyed/individual joists as well as a generated regular joist grid. The generated grid can be hidden once the real floor is exposed.
- The 3D under-floor view includes generated joists, individual surveyed joists and noggins.
- Underfloor heating is positioned at the actual heating layer within the configured floor build-up instead of a fixed arbitrary depth.
- Mobile top navigation is horizontally scrollable rather than wrapping awkwardly, and the missing UI accent variable has been corrected.
- Existing V2.3 product-aware rendering remains: Metro METCC WC, Imperia GR1208CW graphite tray, Milan MILF800WHAOBB vanity, Merton 51120 bath and Arezzo ARZIM10MB mirror.
- Existing black / silver-chrome / brushed-brass finishes remain available for independent shower fittings.

## Migration notes

V2.4 automatically converts older projects:

- old stud-owned shower glass becomes an independent Glass panel item;
- existing mirror/shower fittings are assigned to the new wall-mount model;
- older `.bathplan` projects remain importable and are migrated forward by the main app;
- the current room, fixtures, products, surfaces, floor build-up and existing design data are preserved.

## Update

1. Extract this ZIP.
2. Upload all files over the GitHub Pages repository root.
3. Commit the replacement.
4. Wait for GitHub Pages to deploy.
5. Open the installed planner and use **Reload latest**.


## V2.4.1 focused fixes
- Glass-panel editing no longer repositions the panel just because you change its style, trim, privacy, height or other non-position fields.
- X/Y edits on a mounted glass panel now translate back into its position along the host, so you can move it back instead of it snapping to the previous mount point.
- 2D drag and 3D Move continue to update the same mounted position.
- Under floor is now a floor cutaway: it removes the finished floor and structural deck but keeps the bathroom fixtures and walls visible while exposing the joists underneath.
- Under floor no longer jumps to a separate beams-only camera view. Tap Restore floor to return to the normal room.
